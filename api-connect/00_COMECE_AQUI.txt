🎯 OS 4 CENÁRIOS DE TESTE
═══════════════════════════════════════════════════════════════════════════

✅ Teste 1: Criar Usuário com Sucesso
   POST /users {"nome":"...", "email":"..."}
   → Esperado: HTTP 201

❌ Teste 2: Falha na Validação
   POST /users {"nome":"..."}  (falta email)
   → Esperado: HTTP 400

✅ Teste 3: Listar Todos os Usuários
   GET /users
   → Esperado: HTTP 200 + array de usuários

❌ Teste 4: Buscar ID Inexistente
   GET /users/999
   → Esperado: HTTP 404
